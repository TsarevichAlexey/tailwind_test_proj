Tailwind CSS Test

Тестовая страница для проверки работы Tailwind CSS.

Стек: HTML, Tailwind CSS.

Установка и запуск:

1. npm install -D tailwindcss
2. npx tailwindcss init
3. npx tailwindcss -i ./src/input.css -o ./dist/output.css --watch
4. Открыть index.html в браузере

Структура:

index.html — тестовая страница с кнопкой и заголовком
tailwind.config.js — конфигурация Tailwind, сканирует все .html файлы
